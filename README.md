# Query-Efficient Adaptive Model Extraction of Vision Foundation Models

Code and experiment logs for the pilot-scale empirical study of adaptive query-selection
strategies for black-box model extraction of vision foundation models (CNN / ViT / CLIP victims),
submitted to *IEEE Transactions on Information Forensics and Security (T-IFS)*.

> **Anonymous repository for double-blind review.** No author-identifying information is
> contained in this repository or its commit history.

## Overview

This repository contains the single end-to-end notebook used to produce every number, table,
and figure reported in the paper: victim training, the adaptive query-selection strategy
$S(x)=\alpha U(x)+\beta D(x)+\gamma I(x)$, baseline strategies (random, class-balanced,
uncertainty, diversity), two reproduced few-call/data-free baselines (ASPKD, Stealix-lite),
three attacker stealth levels, a behavioural extraction-risk detector, and a graduated,
risk-scored defense.

## Requirements

- Python 3.10+
- A CUDA-capable GPU (all reported experiments were run on a free-tier single-GPU instance,
  NVIDIA T4-class, ~15 GB, ~30 GPU-hours/week quota — see the paper's Experimental Setup and
  Discussion sections for how this bounds the reported experimental scale)
- `pip install -r requirements.txt`

## Reproducing the results

The notebook is organised into sequential, independently re-runnable phases (victim training →
candidate pool + embeddings → baseline/adaptive strategy comparison → weight grid search →
component ablation → few-call/data-free baselines → query-budget sweep → multi-seed statistics →
victim-family comparison → Imagenette scale-up → attacker stealth levels → extraction-risk
detector → graduated defense). Each experiment cell logs its results and checkpoints
intermediate state so that long-running sweeps (e.g. the 5-seed statistics) can be resumed after
an interruption rather than restarted from scratch. Random seeds used for every reported
statistic are fixed and printed at the top of each corresponding cell.

## Honest scope statement

This is a **pilot-scale** study run under a declared, constrained compute budget, not a
full-scale replication of the originating research proposal. Concretely:

- Core statistics (5-seed, with confidence intervals and a paired $t$-test) are reported only
  for the CNN/ResNet-18 victim on CIFAR-10 at the core query budget.
- ViT, CLIP, and Imagenette-scale results are single-seed and are reported in the paper as a
  pilot-scale signal, not a confirmed claim.
- The full victim×surrogate architecture matrix (matched and mismatched pairs across CNN/ViT/CLIP)
  at the originally proposed scale was not run to completion under this compute budget.
- The extraction-risk detector is trained and evaluated on simulated sessions generated by this
  repository's own attacker code, not on real third-party API traffic.

These limitations are stated explicitly in the paper's Discussion, Limitations, and Threats to
Validity section, and are not hidden or downplayed here.
